# 흔적 열람 페이지 (Reader Highlights) 기획서

> Figma: [수미 작업 공간 — Description List (133:11125)](https://www.figma.com/design/Wl5pM25b53Q0jpA8fi0TUC/?node-id=133-11125)
> 구현 라우트: `app/trace/[id]/` — URL `/trace/[id]` (추후 변경 가능)

## 1. 책 정보 영역

선택한 책의 정보가 표기됩니다.

- **1-a 책 제목과 뒤로가기 버튼**
  - 뒤로가기 버튼 클릭 시 메인으로 이동
- **1-b 발췌된 페이지 탭** — 발췌된 페이지들이 순서대로(오름차순) 보여집니다.
  - 스와이프, 클릭 시 활성화
- **비로그인 시**
  - 남겨진 기록이 얼마 없을 경우 2p~5p 정도
    - 첫 번째 페이지의 기록만 열람할 수 있으며, 다른 페이지를 확인하려 할 시 로그인 유도
    - 남겨진 흔적에서 댓글을 남기려고 할 때도 로그인 유도
    - 로그인 유도 방식: 팝업창
      - "해당 페이지부터는 로그인해야 확인할 수 있어요!"
      - [로그인 하러가기] → 누르면 로그인 페이지로 이동

## 2. 대목(하이라이트) 카드 영역

흔적을 남긴 대목을 확인할 수 있습니다.

- 해당 대목에 사람들이 꾸민 것이 한꺼번에 표기됩니다.
  - **[타인 표기 노출 규칙]** — 노출 대상 선정 (우선순위 순)
    1. 공감 수 많은 순으로 최대 3개 선택
    2. 공감 수 동일할 경우 → 최근에 남긴 순
    3. 날짜도 동일할 경우 → 랜덤 (서버에서 임의 선택)
    - 같은 글자·영역이 겹칠 경우 위 우선순위 기준으로 상위 1개만 노출, 나머지는 제외
  - 하단 흔적에서 각각의 의견 클릭 시 해당 의견을 남긴 사람이 기록한 문장 꾸밈 표기 확인 가능
  - 흔적 외 댓글은 흔적을 남기지 않아도 확인 가능하며, 댓글 및 좋아요를 누를 수 있습니다.
- **2-b 대목 넘겨보기** — 같은 페이지에 여러 대목이 남겨진 경우 해당 부분을 통해 넘겨볼 수 있습니다. 루프 형태.
- **스포일러 처리** — 스포일러 표기가 된 대목은 해당 페이지에서 블러 처리되며, [버튼]을 눌러야 대목+흔적을 확인할 수 있습니다.

## 3. 의견(흔적) 리스트 영역

의견을 확인할 수 있습니다.

- 남겨진 모든 의견을 확인할 수 있습니다. (스포일러 된 의견 제외)
  모든 의견은 스크롤을 내려 계속 확인이 가능합니다.
  - 흔적 부분을 보기 위해 스크롤 시 위의 디자인이 살짝 변형됩니다. (흔적을 더 잘 보기 위한)
    - 변형된 디자인: 상단 = 대목, 하단 = 흔적 리스트
    - 상단(대목)은 고정이며, 하단에서 의견들을 확인. 이유: 의견마다 달라지는 꾸밈 정도를 확인하기 위함.
    - 상단 270px 고정 / 하단 남은 공간 안에서 의견이 스크롤됩니다.
  - 스포일러된 의견은 대목과 마찬가지로 댓글 부분에 블러 처리된 후 흔적 보기 버튼을 통해 확인
- 스크롤을 위로 올릴 시 포스트잇 디자인 형태에서 흔적을 보기 편한 디자인으로 변경되며, 대목 부분은 sticky 형태로 유지됩니다. (의견 클릭 시 어떻게 꾸몄는지 확인할 수 있도록)
- **3-a 의견 구성** — [닉네임], [의견], [남겨진 날짜] 순서로 확인 가능
  - [남겨진 날짜] 표기 규칙 (default)
    - 현재 날짜 기준 3일이 지나지 않았을 때: `1일 전`, `2일 전`, `3일 전`
      - 24시간이 지나지 않은 경우: `12시간 전`처럼 시간 단위로 표기
    - 3일 이후부터는 날짜로 표기: `yyyy-mm-dd`
  - `n개의 흔적` 옆에 정렬 기능: 최신 순(default) / 좋아요 순
  - 의견은 최대 3줄까지 노출되며, 더 많은 경우 `...`으로 표기되고 클릭 시 전체 확인 가능
- **3-b 액션** — [좋아요], [댓글], [신고하기]
  - 좋아요를 누르면 누른 표기가 변경되며, 100개가 넘어갈 시 `99+`로 표기 고정
  - 댓글 아이콘을 누를 경우 댓글을 입력할 수 있는 페이지로 이동, 남겨진 댓글도 확인 가능
    - 페이지 대신 해당 페이지 내에서 댓글을 입력하는 것으로 가도 됩니다.
    - 댓글 입력 시 대댓글 형태로 남겨지며, 대댓글에는 댓글을 남길 수 없음. 추후 멘션(@닉네임) 기능으로 의견 알림 확장 예정
  - (추후 기능) 신고하기 — 스팸/혐오/욕설/저작권/기타 선택 모달

## 4. 책 흔적 상태 표기

책 흔적을 남길 때 상태 표기 (읽는 중 / 읽을 예정)

- **읽는 중**: 어디까지 읽었는지 페이지 표시, 그 이후 페이지는 내용이 보이지 않음
- **읽을 예정**: 첫 부분만 보여주고 이후는 보이지 않음 (스포 방지)
